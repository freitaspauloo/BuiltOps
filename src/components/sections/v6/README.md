Scoped under `[data-microsite-version="v6"]` in `globals.css` + this snapshot:

2. **Rhythm** — compact padding on buy-path (site plan → floorplans → QMI)
3. **Labels** — unified uppercase label token + darker muted
4. **CTA scarcity** — Explore = outline; Book a Tour = secondary; Compare = secondary; primary reserved for lead intent
5. **Surface** — design centre un-muted; testimonials keep the mist band
6. **Axis** — left-aligned floorplans / QMI intros
7. **Site plan** — CTA centered on the plan (same as v5 treatment)
8. **Registration** — stronger inset treatment
9. **Gallery lightbox** — Yet Another React Lightbox (zoom, thumbnails, captions, counter)
